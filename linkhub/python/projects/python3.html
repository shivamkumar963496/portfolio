🔐 Python Mini Project 3 - Password Strength Checker

# -----------------------------------------------------------
# Question:
# Python me ek program likhiye jo user se password le aur
# uski strength (Weak, Medium, Strong) check kare using
# string aur conditions.
# -----------------------------------------------------------

# user se password lena
password = input("Enter your password: ")

# password ki length nikalna
length = len(password)

# flags create karna
has_digit = False
has_special = False

# password ke har character ko check karna
for ch in password:

    # digit check karna
    if ch.isdigit():
        has_digit = True

    # special character check karna
    if ch in "!@#$%^&*":
        has_special = True

# password strength check karna
if length < 6:

    print("Weak Password")

elif length >= 6 and has_digit and has_special:

    print("Strong Password")

else:

    print("Medium Password")
📊 Sample Output 1:

Enter your password: 123
Weak Password
📊 Sample Output 2:

Enter your password: Shivam123
Medium Password
📊 Sample Output 3:

Enter your password: Shivam@123
Strong Password
📝 Explanation:

1. User se password input liya jata hai.
2. len() function password ki length nikalta hai.
3. Loop password ke har character ko check karta hai.
4. isdigit() digit ko identify karta hai.
5. Special characters (!@#$%^&*) ko alag se check kiya jata hai.
6. Length 6 se kam ho to Weak Password.
7. Length 6+ ho aur digit + special character dono ho to Strong Password.
8. Baaki cases me Medium Password display hota hai.
