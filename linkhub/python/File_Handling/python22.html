📌 Python File Handling Program 22

# Question 22:
# Ek Python program likho jo ek image file ko
# copy karke dusri image file me save kare.

# source image ko binary read mode me open karna
with open("image1.jpg","rb") as f1:

    # destination image ko binary write mode me open karna
    with open("image2.jpg","wb") as f2:

        # source image ka data read karke
        # destination image me write karna
        f2.write(f1.read())

# success message print karna
print("Image Copied Successfully")
📊 Output:

Image Copied Successfully
📝 Explanation:

1. image1.jpg ko binary read mode ("rb") me open kiya gaya hai.
2. image2.jpg ko binary write mode ("wb") me open kiya gaya hai.
3. f1.read() source image ka pura binary data read karta hai.
4. f2.write() us data ko destination image me save karta hai.
5. Program complete hone ke baad image2.jpg image1.jpg ki exact copy ban jati hai.
6. with statement files ko automatically close kar deta hai.
⭐ Important Point:

✔ rb = Read Binary Mode
✔ wb = Write Binary Mode
✔ Binary files (Image, Audio, Video, PDF) copy karte waqt binary mode use karna zaroori hai.
✔ with statement use karne se close() manually likhne ki zaroorat nahi hoti.
