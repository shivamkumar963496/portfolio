🎮 Python Mini Project 1 - Number Guessing Game

# -----------------------------------------------------------
# Question:
# Python me ek program likhiye jo 1 se 100 ke beech ek random
# number generate kare aur user se us number ko guess karvaye.
# Har guess par bataye ki number bada hai ya chota.
# Jab sahi guess ho jaye to total attempts print kare.
# -----------------------------------------------------------

# random module import kar rahe hain
import random

# 1 se 100 ke beech random number generate kar rahe hain
number = random.randint(1, 100)

# attempts count karne ke liye variable
attempts = 0

# welcome message display
print("\nWelcome to Number Guessing Game")

# loop tab tak chalega jab tak correct guess na ho
while True:

    # user se input lena
    guess = int(input("Enter your guess (1-100): "))

    # check karna ki input valid range me hai ya nahi
    if guess < 1 or guess > 100:
        print("Please enter number between 1 and 100")
        continue

    # har valid guess par attempts badhana
    attempts += 1

    # condition check karna
    if guess > number:
        print("YE NUMBER BADA HO GAYA")

    elif guess < number:
        print("YE NUMBER CHOTA HO GAYA")

    else:
        print("Correct Guess!")
        print("AAPNE TOTAL ATTEMPTS LIYE :", attempts)
        break

📝 Explanation:

1. random.randint(1,100) random secret number generate karta hai.
2. User baar-baar number guess karta hai.
3. Agar guess bada ho to "YE NUMBER BADA HO GAYA" print hota hai.
4. Agar guess chota ho to "YE NUMBER CHOTA HO GAYA" print hota hai.
5. Sahi guess hone par game stop ho jata hai.
6. Total attempts bhi display kiye jate hain.
