📌 Python File Handling Program 5

# Question 5:
# Ek Python program likho jo file ko
# line by line read karke print kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ki har line ko ek-ek karke read karna
for line in file:

    # current line print karna
    print(line)

# file close karna
file.close()
📊 Output:

demo.txt file ki sabhi lines ek-ek karke print hongi.
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. for line in file loop file ki har line ko automatically read karta hai.
3. Har iteration me ek line line variable me store hoti hai.
4. print(line) us line ko screen par display karta hai.
5. Last me file.close() file ko band kar deta hai.
⭐ Important Point:

✔ Large files ko line-by-line read karna memory efficient hota hai.
✔ Puri file ek saath load nahi hoti.
✔ Ye method log files aur large text files ke liye bahut useful hai.
