# Question 13:
# Ek Python program likho jo else block ka use kare.

# try block create karna
try:

    # division perform karna
    print(10 / 2)

# exception handle karna
except:

    # error message print karna
    print("Error")

# else block create karna
else:

    # success message print karna
    print("Program Execution Successful")
📊 Output:

5.0
Program Execution Successful
