📌 Python File Handling Program 23

# Question 23:
# Ek Python program likho jo kisi file ko delete kare.

# os module import karna
import os

# file delete karna
os.remove("demo.txt")

# success message print karna
print("File Deleted Successfully")
📊 Output:

File Deleted Successfully
📝 Explanation:

1. import os operating system related functions use karne ke liye import kiya jata hai.
2. os.remove("demo.txt") specified file ko permanently delete kar deta hai.
3. Agar file successfully delete ho jati hai to success message display hota hai.
4. Delete hone ke baad file folder se remove ho jati hai.
5. Program execute karne se pehle file ka naam sahi hona chahiye.
⭐ Important Point:

✔ os.remove() file delete karne ke liye use hota hai.
✔ Agar file exist nahi karti to FileNotFoundError aa sakta hai.
✔ Important files delete karne se pehle existence check karna achhi practice hai.
