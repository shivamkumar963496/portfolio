📌 Python File Handling Program 13

# Question 13:
# Ek Python program likho jo file me
# kisi specific word ko search kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ka pura data read karna
data = file.read()

# search karne wala word
word = "Python"

# word file me hai ya nahi check karna
if word in data:

    # word mil gaya
    print("Word Found")

else:

    # word nahi mila
    print("Word Not Found")

# file close karna
file.close()
📊 Output:

Word Found

OR

Word Not Found
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. read() file ka pura content read karta hai.
3. Search karne wala word word variable me store kiya gaya hai.
4. if word in data check karta hai ki word file me present hai ya nahi.
5. Agar word mil jata hai to Word Found print hota hai.
6. Agar word nahi milta to Word Not Found print hota hai.
⭐ Important Point:

✔ in operator string searching ke liye use hota hai.
✔ Search case-sensitive hoti hai.
✔ "Python" aur "python" alag-alag values mani jati hain.
