📌 Python File Handling Program 29

# Question 29:
# Ek Python program likho jo JSON file me
# data write kare.

# json module import karna
import json

# dictionary data create karna
data = {
    "name":"Shivam"
}

# JSON file ko write mode me open karna
with open("data.json","w") as file:

    # dictionary data JSON file me save karna
    json.dump(data,file)

# success message print karna
print("JSON File Created Successfully")
📊 Output:

JSON File Created Successfully

data.json Content: 
{"name":"Shivam"}
📝 Explanation:

1. import json JSON files handle karne ke liye use kiya jata hai.
2. Ek Python dictionary data create ki gayi hai.
3. data.json file write mode me open ki jati hai.
4. json.dump() dictionary ko JSON format me convert karke file me save karta hai.
5. with statement file ko automatically close kar deta hai.
6. Program execute hone ke baad data.json file create ho jati hai.
⭐ Important Point:

✔ JSON = JavaScript Object Notation.
✔ JSON data exchange ke liye bahut popular format hai.
✔ Python dictionary ko JSON file me save karne ke liye json.dump() use hota hai.
✔ APIs aur web applications me JSON ka bahut use hota hai.
