📌 Python File Handling Program 24

# Question 24:
# Ek Python program likho jo ek file ka naam
# badal kar naya naam de.

# os module import karna
import os

# file ka naam change karna
os.rename("old.txt","new.txt")

# success message print karna
print("File Renamed Successfully")
📊 Output:

File Renamed Successfully
📝 Explanation:

1. import os operating system functions use karne ke liye import kiya jata hai.
2. os.rename("old.txt","new.txt") old file ka naam badal kar new naam de deta hai.
3. Rename operation ke baad purana naam exist nahi karta.
4. File ka content same rehta hai, sirf naam change hota hai.
5. Success hone par message display hota hai.
⭐ Important Point:

✔ os.rename(old_name, new_name) file ya folder dono ka naam change kar sakta hai.
✔ Agar old file exist nahi karti to FileNotFoundError aa sakta hai.
✔ Rename karte samay naya naam unique hona chahiye.
