# Question 31:
# Ek Python program likho jo file handling exception handle kare.

# try block create karna
try:

    # file open karna
    file = open("Demo.txt", "r")

    # file data print karna
    print(file.read())

# exception handle karna
except Exception as e:

    # error message print karna
    print(e)
📊 Output:

[Errno 2] No such file or directory: 'Demo.txt'
