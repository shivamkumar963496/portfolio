# Question 14:
# Ek Python program likho jo file me
# total vowels (a, e, i, o, u) count kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ka pura data read karna
data = file.read()

# data ko lowercase me convert karna
data = data.lower()

# vowel counter variable
count = 0

# har character check karna
for ch in data:

    # agar character vowel hai
    if ch in "aeiou":

        # counter increase karna
        count += 1

# total vowels print karna
print("Total Vowels:", count)

# file close karna
file.close()
📊 Output:

Total Vowels: 12
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. read() file ka pura content read karta hai.
3. lower() text ko lowercase me convert karta hai taaki A aur a dono count ho sakein.
4. for loop har character ko check karta hai.
5. Agar character aeiou me milta hai to count 1 se badh jata hai.
6. Last me total vowels display kiye jate hain.
⭐ Important Point:

✔ Vowels = a, e, i, o, u
✔ lower() use karne se uppercase vowels bhi count ho jate hain.
✔ Ye program String Handling aur File Handling dono concepts use karta hai.
