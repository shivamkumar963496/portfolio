📌 Python File Handling Program 28

# Question 28:
# Ek Python program likho jo CSV file ka data
# read karke display kare.

# csv module import karna
import csv

# CSV file ko read mode me open karna
with open("student.csv","r") as file:

    # csv reader object create karna
    reader = csv.reader(file)

    # har row ko read karke print karna
    for row in reader:

        print(row)
📊 Output:

['ID', 'Name']
['101', 'Shivam']
📝 Explanation:

1. import csv CSV files ko handle karne ke liye use kiya jata hai.
2. student.csv file read mode me open ki jati hai.
3. csv.reader() CSV file ko row-by-row read karta hai.
4. for row in reader loop har row ko access karta hai.
5. Har row list ke form me return hoti hai.
6. print(row) row ka data screen par display karta hai.
⭐ Important Point:

✔ CSV file ki har row Python list ke roop me read hoti hai.
✔ csv.reader() tabular data ko process karne ke liye use hota hai.
✔ CSV files Excel aur database exports me bahut commonly use hoti hain.
✔ Large CSV files ko row-by-row process karna memory efficient hota hai.
