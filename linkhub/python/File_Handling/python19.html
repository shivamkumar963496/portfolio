📌 Python File Handling Program 19

# Question 19:
# Ek Python program likho jo file ka
# content reverse order me print kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ka pura content read karna
data = file.read()

# reverse content print karna
print(data[::-1])

# file close karna
file.close()
📊 Output:

nohtyP ot emocleW
dlroW olleH
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. read() file ka pura content read karta hai.
3. data[::-1] slicing ka use karke string ko reverse karta hai.
4. Reverse content screen par print hota hai.
5. Last me file ko close kar diya jata hai.
⭐ Important Point:

✔ [::-1] Python me string reverse karne ka shortcut hai.
✔ Original file ka content change nahi hota.
✔ Sirf display ke liye reverse text generate hota hai.
