📌 Python File Handling Program 9

# Question 9:
# Ek Python program likho jo file ka content
# UPPERCASE me print kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ka data read karna
data = file.read()

# data ko uppercase me convert karke print karna
print(data.upper())

# file close karna
file.close()
📊 Output:

HELLO WORLD
WELCOME TO PYTHON
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. read() file ka pura content read karta hai.
3. upper() string ke sabhi lowercase letters ko uppercase me convert karta hai.
4. print() converted text ko screen par display karta hai.
5. close() file ko properly band karta hai.
⭐ Important Point:

✔ upper() original file ka data change nahi karta.
✔ Sirf display ke liye uppercase version banata hai.
✔ String manipulation aur file handling ka combination hai.
