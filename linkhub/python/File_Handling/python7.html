📌 Python File Handling Program 7

# Question 7:
# Ek Python program likho jo file me total
# lines ki sankhya count kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ki sabhi lines ko read karna
lines = file.readlines()

# total lines print karna
print("Total Lines:", len(lines))

# file close karna
file.close()
📊 Output:

Total Lines: 5
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. readlines() file ki sabhi lines ko list ke roop me read karta hai.
3. Har line list ka ek element banti hai.
4. len(lines) list ke total elements yani total lines count karta hai.
5. Result screen par display hota hai.
⭐ Important Point:

✔ readlines() file ki sabhi lines ko list me store karta hai.
✔ len() ka use karke total line count aasani se nikala ja sakta hai.
✔ Large files ke liye readlines() zyada memory use kar sakta hai.
