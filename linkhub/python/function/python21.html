# Question 21:
# Ek Python program likho jo function me return keyword ka use karke
# do numbers ka sum return kare.

# function create karna
def add(a, b):

    # sum return karna
    return a + b

# user se input lena
m = int(input("Enter the Value of a : "))
n = int(input("Enter the Value of b : "))

# function call karke result store karna
x = add(m, n)

# final output print karna
print("The Sum of a and b :", x)
📊 Output:

Enter the Value of a : 10
Enter the Value of b : 20
The Sum of a and b : 30
