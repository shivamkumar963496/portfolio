📌 Python File Handling Program 20

# Question 20:
# Ek Python program likho jo file ki empty lines
# remove karke nayi file me save kare.

# source file ko read mode me open karna
with open("file1.txt","r") as f:

    # sirf non-empty lines store karna
    lines = [line for line in f if line.strip()]

# new file ko write mode me open karna
with open("file2.txt","w") as f:

    # filtered lines write karna
    f.writelines(lines)

# success message print karna
print("Empty Lines Removed Successfully")
📊 Output:

Empty Lines Removed Successfully
📝 Explanation:

1. file1.txt ko read mode me open kiya gaya hai.
2. line.strip() line ke starting aur ending spaces remove karta hai.
3. Agar line empty nahi hai to use list me store kiya jata hai.
4. file2.txt ko write mode me open kiya jata hai.
5. writelines() filtered lines ko new file me save karta hai.
6. Is tarah empty lines remove hokar clean file create ho jati hai.
⭐ Important Point:

✔ strip() spaces aur newline characters remove karta hai.
✔ Empty line detect karne ke liye strip() bahut useful hai.
✔ Data cleaning aur preprocessing me ye technique frequently use hoti hai.
