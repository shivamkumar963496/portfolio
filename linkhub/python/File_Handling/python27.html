📌 Python File Handling Program 27

# Question 27:
# Ek Python program likho jo CSV file create kare
# aur usme student data store kare.

# csv module import karna
import csv

# CSV file ko write mode me open karna
with open("student.csv","w",newline="") as file:

    # csv writer object create karna
    writer = csv.writer(file)

    # heading row add karna
    writer.writerow(["ID","Name"])

    # student record add karna
    writer.writerow([101,"Shivam"])

# success message print karna
print("CSV File Created Successfully")
📊 Output:

CSV File Created Successfully

student.csv Content: 
ID,Name
101,Shivam
📝 Explanation:

1. import csv CSV files handle karne ke liye use kiya jata hai.
2. student.csv file write mode me open ki jati hai.
3. csv.writer() writer object create karta hai.
4. writer.writerow() ek row CSV file me add karta hai.
5. Pehli row heading hai aur doosri row student record hai.
6. with statement file ko automatically close kar deta hai.
⭐ Important Point:

✔ CSV = Comma Separated Values.
✔ CSV files spreadsheet aur Excel data store karne ke liye use hoti hain.
✔ newline="" extra blank lines ko avoid karne ke liye use kiya jata hai.
✔ CSV files database export/import me bahut common hain.
