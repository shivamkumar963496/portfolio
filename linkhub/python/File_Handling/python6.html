📌 Python File Handling Program 6

# Question 6:
# Ek Python program likho jo file me total
# words ki sankhya count kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ka pura data read karna
data = file.read()

# data ko words me divide karna
words = data.split()

# total words print karna
print("Total words:", len(words))

# file close karna
file.close()
📊 Output:

Total words: 15
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. read() file ka pura content read karta hai.
3. split() text ko words me convert karta hai.
4. len(words) total words count karta hai.
5. Result screen par print hota hai.
⭐ Important Point:

✔ split() default roop se spaces ke basis par words ko alag karta hai.
✔ len() list ke total elements count karta hai.
✔ Word counting text analysis me bahut useful hai.
