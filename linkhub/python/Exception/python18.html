# Question 18:
# Ek Python program likho jo low balance exception handle kare.

# initial balance create karna
balance = 10000

# try block create karna
try:

    # user se withdrawal amount input lena
    amount = int(input("Enter Withdrawal Amount : "))

    # balance check karna
    if amount > balance:

        # custom exception raise karna
        raise Exception("Low Balance")

    # success message print karna
    print("Withdrawal Success")

# exception handle karna
except Exception as e:

    # error message print karna
    print(e)
📊 Output:

Enter Withdrawal Amount : 15000

Low Balance
