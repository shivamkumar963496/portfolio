📌 Python File Handling Program 15

# Question 15:
# Ek Python program likho jo user se
# 3 students ke naam input lekar file me save kare.

# students.txt file ko write mode me open karna
file = open("students.txt","w")

# 3 baar loop chalana
for i in range(3):

    # student ka naam input lena
    name = input("Enter Student Name : ")

    # naam ko file me save karna
    file.write(name + "\n")

# file close karna
file.close()

# success message print karna
print("Student Names Saved Successfully")
📊 Output:

Enter Student Name : Rahul
Enter Student Name : Mohit
Enter Student Name : Aman

Student Names Saved Successfully
📝 Explanation:

1. students.txt file ko write mode me open kiya gaya hai.
2. for i in range(3) loop 3 baar execute hota hai.
3. Har baar user se ek student ka naam input liya jata hai.
4. file.write() naam ko file me save karta hai.
5. \n new line ke liye use hota hai taaki har naam alag line me save ho.
6. Last me file close karke success message display kiya jata hai.
⭐ Important Point:

✔ \n new line character hai.
✔ Loop ka use karke multiple records store kiye ja sakte hain.
✔ File Handling me user input save karne ka ye basic example hai.
