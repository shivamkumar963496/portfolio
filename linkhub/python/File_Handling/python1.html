📌 Python File Handling Program 1

# Question 1:
# Ek Python program likho jo ek text file create kare
# aur usme "Hello World" write kare.

# data.txt file ko write mode me open karna
file = open("data.txt","w")

# file ke andar text likhna
file.write("Hello World")

# file close karna
file.close()

# success message print karna
print("Data Written Successfully")
📊 Output:

Data Written Successfully
📝 Explanation:

1. open("data.txt","w") file ko write mode me open karta hai.
2. Agar file exist nahi karti to Python automatically new file create kar deta hai.
3. write() function file ke andar data save karta hai.
4. close() file ko properly band karta hai.
5. Program run hone ke baad data.txt file me Hello World save ho jayega.
⭐ Important Point:

✔ "w" mode purani file ka data overwrite kar deta hai.
✔ File Handling ka ye sabse basic program hai.
