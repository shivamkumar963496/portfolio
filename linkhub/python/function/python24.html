# Question 24:
# Ek Python program likho jo function aur return keyword ka use karke
# greeting message return kare.

# function create karna
def greet():

    # greeting message return karna
    return "Hello Shivam"

# function call karke direct print karna
print(greet())

# function ka returned value variable me store karna
x = greet()

# stored value print karna
print(x)
📊 Output:

Hello Shivam
Hello Shivam
