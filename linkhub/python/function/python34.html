# Question 34:
# Ek Python program likho jo lambda function ka use karke
# do numbers me maximum number find kare.

# lambda function create karna
maximum = lambda a, b: a if a > b else b

# user se input lena
m = int(input("Enter 1st Number : "))
n = int(input("Enter 2nd Number : "))

# maximum number print karna
print("The Maximum Number Is :", maximum(m, n))
📊 Output:

Enter 1st Number : 40
Enter 2nd Number : 70
The Maximum Number Is : 70
