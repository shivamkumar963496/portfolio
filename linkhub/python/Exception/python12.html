# Question 12:
# Ek Python program likho jo multiple exceptions handle kare.

# try block create karna
try:

    # user se input lena
    a = int(input("Enter 1st Number : "))
    b = int(input("Enter 2nd Number : "))

    # division perform karna
    print(a / b)

# ZeroDivisionError handle karna
except ZeroDivisionError:

    # error message print karna
    print("Cannot Divide By Zero")

# ValueError handle karna
except ValueError:

    # invalid input message print karna
    print("Invalid Input")
📊 Output:

Enter 1st Number : 10
Enter 2nd Number : 0

Cannot Divide By Zero
