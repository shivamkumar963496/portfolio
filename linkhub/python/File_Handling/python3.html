📌 Python File Handling Program 3

# Question 3:
# Ek Python program likho jo existing file me
# naya data append kare bina purana data delete kiye.

# data.txt file ko append mode me open karna
file = open("data.txt","a")

# file ke end me naya text add karna
file.write(" Welcome to Python")

# file close karna
file.close()

# success message print karna
print("Data Appended Successfully")
📊 Output:

Data Appended Successfully
📝 Explanation:

1. open("data.txt","a") file ko append mode me open karta hai.
2. Append mode purane data ko delete nahi karta.
3. write() function file ke end me naya data add karta hai.
4. close() file ko properly band karta hai.
5. Agar file me pehle Hello World tha to append ke baad file me:

Hello World Welcome to Python
⭐ Important Point:

✔ "a" mode existing data ko preserve karta hai.
✔ Agar file exist nahi karti to Python new file create kar deta hai.
✔ Append mode logs aur records store karne ke liye bahut useful hai.
