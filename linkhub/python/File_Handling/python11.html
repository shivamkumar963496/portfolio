📌 Python File Handling Program 11

# Question 11:
# Ek Python program likho jo ek file ka data
# dusri file me copy kare.

# source file ko read mode me open karna
f1 = open("source.txt","r")

# destination file ko write mode me open karna
f2 = open("destination.txt","w")

# source file ka data read karke
# destination file me write karna
f2.write(f1.read())

# dono files close karna
f1.close()
f2.close()

# success message print karna
print("File Copied Successfully")
📊 Output:

File Copied Successfully
📝 Explanation:

1. source.txt ko read mode me open kiya gaya hai.
2. destination.txt ko write mode me open kiya gaya hai.
3. f1.read() source file ka pura content read karta hai.
4. f2.write() us content ko destination file me save karta hai.
5. Dono files ko close kar diya jata hai.
6. Program execute hone ke baad source file ka pura data destination file me copy ho jata hai.
⭐ Important Point:

✔ File copy karne ke liye read() aur write() ka combination use hota hai.
✔ Destination file pehle se exist ho to uska purana data overwrite ho sakta hai.
✔ Backup aur data transfer ke liye ye technique useful hai.
