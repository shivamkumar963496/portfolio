📌 Python File Handling Program 30

# Question 30:
# Ek Python program likho jo JSON file ka
# data read karke display kare.

# json module import karna
import json

# JSON file ko read mode me open karna
with open("data.json","r") as file:

    # JSON data ko Python object me convert karna
    data = json.load(file)

# data print karna
print(data)
📊 Output:

{'name': 'Shivam'}
📝 Explanation:

1. import json JSON data ko handle karne ke liye use kiya jata hai.
2. data.json file read mode me open ki jati hai.
3. json.load(file) JSON file ke data ko read karta hai.
4. JSON data Python dictionary me convert ho jata hai.
5. Converted data data variable me store hota hai.
6. print(data) dictionary ko screen par display karta hai.
⭐ Important Point:

✔ json.dump() data ko JSON file me write karta hai.
✔ json.load() JSON file se data read karta hai.
✔ JSON file read karne ke baad data Python dictionary ke form me milta hai.
✔ APIs se aane wala data aksar JSON format me hota hai.
