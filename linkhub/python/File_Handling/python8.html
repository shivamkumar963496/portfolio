📌 Python File Handling Program 8

# Question 8:
# Ek Python program likho jo user se data input le
# aur use file me save kare.

# user se input lena
name = input("Enter your name: ")

# file ko write mode me open karna
file = open("user.txt","w")

# input data file me write karna
file.write(name)

# file close karna
file.close()

# success message print karna
print("Data Saved Successfully")
📊 Output:

Enter your name: Shivam
Data Saved Successfully
📝 Explanation:

1. input() function user se data leta hai.
2. open("user.txt","w") file ko write mode me open karta hai.
3. write() user ka data file me save karta hai.
4. close() file ko properly close karta hai.
5. Program run hone ke baad user.txt file me entered name save ho jayega.
⭐ Important Point:

✔ User input ko permanently store karne ke liye file handling use hoti hai.
✔ "w" mode purana data overwrite kar deta hai.
✔ Database se pehle basic data storage ke liye files ka use kiya jata hai.
