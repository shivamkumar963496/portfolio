# Question 32:
# Ek Python program likho jo lambda function ka use karke
# kisi number ka square calculate kare.

# lambda function create karna
square = lambda x: x * x

# user se number input lena
x = int(input("Enter a Number : "))

# square calculate karke output print karna
print("The Square of Given Number :", square(x))
📊 Output:

Enter a Number : 6
The Square of Given Number : 36
