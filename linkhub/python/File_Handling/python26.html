📌 Python File Handling Program 26

# Question 26:
# Ek Python program likho jo FileNotFoundError
# ko handle kare.

# try block me risky code likhna
try:

    # non-existing file open karna
    file = open("abc.txt","r")

    # file ka data print karna
    print(file.read())

    # file close karna
    file.close()

# agar file nahi mile to exception handle karna
except FileNotFoundError:

    # error message print karna
    print("File Not Found")
📊 Output:

File Not Found
📝 Explanation:

1. try block me wo code likha jata hai jahan error aane ki possibility hoti hai.
2. Program abc.txt file ko open karne ki koshish karta hai.
3. Agar file exist nahi karti to Python FileNotFoundError raise karta hai.
4. Control automatically except FileNotFoundError block me chala jata hai.
5. Error aane par program crash nahi hota aur user-friendly message display hota hai.
6. Is process ko Exception Handling kehte hain.
⭐ Important Point:

✔ Exception Handling program ko crash hone se bachati hai.
✔ try me risky code aur except me error handling code likha jata hai.
✔ File Handling me FileNotFoundError sabse common exceptions me se ek hai.
✔ Professional applications me hamesha proper exception handling use karni chahiye.
