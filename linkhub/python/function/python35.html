# Question 35:
# Ek Python program likho jo lambda function ka use karke
# kisi number ka cube calculate kare.

# lambda function create karna
cube = lambda a: a ** 3

# user se number input lena
a = int(input("Enter a Number : "))

# cube calculate karke output print karna
print("Cube of Given Number :", cube(a))
📊 Output:

Enter a Number : 3
Cube of Given Number : 27
