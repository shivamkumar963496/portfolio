🔢 Python Mini Project 4 - Even Odd Counter

# -----------------------------------------------------------
# Question:
# Python me ek program likhiye jo user se kuch numbers le
# aur unme se even aur odd numbers ki sankhya count kare
# using loops aur conditions.
# -----------------------------------------------------------

# User se puchna kitne numbers input karne hain
n = int(input("Enter How Many Numbers : "))

# Even aur odd counters initialize karna
even = 0
odd = 0

# Loop chalana numbers input ke liye
for i in range(n):

    # User se number lena
    num = int(input("Enter Number : "))

    # Check karna even ya odd
    if num % 2 == 0:

        # Even count increase
        even += 1

    else:

        # Odd count increase
        odd += 1

# Final result print karna
print("\nTotal Even Numbers =", even)
print("Total Odd Numbers  =", odd)
📊 Sample Output:

Enter How Many Numbers : 5

Enter Number : 10
Enter Number : 15
Enter Number : 20
Enter Number : 25
Enter Number : 30

Total Even Numbers = 3
Total Odd Numbers = 2
📝 Explanation:

1. User se total numbers ki quantity li jati hai.
2. Even aur Odd ke liye alag counters banaye jate hain.
3. Loop ke through numbers input liye jate hain.
4. num % 2 == 0 se even number check kiya jata hai.
5. Even hone par even counter increase hota hai.
6. Odd hone par odd counter increase hota hai.
7. Last me total even aur odd numbers display kiye jate hain.
