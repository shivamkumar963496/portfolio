Python Modules Complete Revision 🚀

Complete Notes with Explanation, Examples and Comments

1. What is Module?

Python में ऐसी file जिसमें functions, variables, classes और reusable code होता है उसे Module कहते हैं।

Example


# math.py

def add(a,b):
    return a+b

ऊपर की file एक module है क्योंकि इसमें reusable function है।

2. Import Module

Module को use करने के लिए import keyword का use करते हैं। 


# math module import

import math

# square root निकालना

print(math.sqrt(25))

Output


5.0

3. Specific Function Import

अगर पूरा module import नहीं करना चाहते तो specific function import कर सकते हैं। 


# sqrt function import

from math import sqrt

# direct use

print(sqrt(36))

4. Alias Name

बड़े module names को छोटा करने के लिए alias name use करते हैं। 


# math module को m नाम दिया

import math as m

print(m.pi)

5. Random Module

Random numbers generate करने के लिए random module use होता है। 


import random

# 1 से 10 तक random number

print(random.randint(1,10))

6. Datetime Module

Date और Time handle करने के लिए datetime module use होता है। 


from datetime import datetime

# current date & time

now = datetime.now()

print(now)

7. OS Module

Operating System related काम करने के लिए os module use होता है। 


import os

# current folder path

print(os.getcwd())

# current folder files

print(os.listdir())

8. SYS Module

Python interpreter information के लिए sys module use होता है। 


import sys

# python version

print(sys.version)

9. Calendar Module

Calendar print करने के लिए calendar module use होता है। 


import calendar

# June 2026 calendar

print(calendar.month(2026,6))

10. JSON Module

JSON data handle करने के लिए json module use होता है। 


import json

x='{"name":"Shivam"}'

# JSON to Python dictionary

print(json.loads(x))

11. Custom Module

हम अपनी खुद की module file भी बना सकते हैं।

mymodule.py


# function create

def greet():

    print("Hello Shivam")

main.py


# custom module import

import mymodule

# function call

mymodule.greet()

12. Package Example

कई modules के collection को Package कहते हैं। 


mypackage/

    add.py
    sub.py

Import Example


from mypackage.add import sum

13. __name__ Variable

यह check करता है कि file direct run हुई है या import हुई है। 


def show():

    print("Hello")

# direct run check

if __name__ == "__main__":

    show()

14. Reload Module

Module को दुबारा reload करने के लिए importlib module use होता है। 


import importlib
import math

# reload module

importlib.reload(math)
