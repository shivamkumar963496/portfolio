# Question 40:
# Ek Python program likho jo magic method __len__() ka use karke
# object ki custom length return kare.

# class create karna
class Demo:

    # magic method create karna
    def __len__(self):

        # custom length return karna
        return 5

# object create karna
d = Demo()

# len() function call karna
print(len(d))
📊 Output:

5
