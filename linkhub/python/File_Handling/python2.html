📌 Python File Handling Program 2

# Question 2:
# Ek Python program likho jo kisi text file ka
# pura data read karke screen par print kare.

# data.txt file ko read mode me open karna
file = open("data.txt","r")

# file ka pura content read karke print karna
print(file.read())

# file close karna
file.close()
📊 Output:

Hello World
📝 Explanation:

1. open("data.txt","r") file ko read mode me open karta hai.
2. read() function file ka pura content read karta hai.
3. print() screen par data display karta hai.
4. close() file ko properly close karta hai.
5. Agar file me "Hello World" likha hai to wahi output me show hoga.
⭐ Important Point:

✔ "r" mode sirf file read karne ke liye use hota hai.
✔ Agar file exist nahi karti to FileNotFoundError aata hai.
✔ read() pura content ek saath read karta hai.
