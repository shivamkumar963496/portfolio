# Question 31:
# Ek Python program likho jo lambda function ka use karke
# do numbers ka addition kare.

# lambda function create karna
add = lambda a, b: a + b

# user se input lena
m = int(input("Enter 1st Number : "))
n = int(input("Enter 2nd Number : "))

# lambda function call karke output print karna
print("Sum of a and b :", add(m, n))
📊 Output:

Enter 1st Number : 10
Enter 2nd Number : 20
Sum of a and b : 30
