📌 Python File Handling Program 4

# Question 4:
# Ek Python program likho jo file ke
# first 20 characters read karke print kare.

# data.txt file ko read mode me open karna
file = open("data.txt","r")

# file ke pehle 20 characters read karna
data = file.read(20)

# data print karna
print(data)

# file close karna
file.close()
📊 Output:

Hello World Welcome
📝 Explanation:

1. open("data.txt","r") file ko read mode me open karta hai.
2. read(20) file ke sirf pehle 20 characters read karta hai.
3. Puri file read nahi hoti, sirf specified characters hi read hote hain.
4. print() data ko screen par display karta hai.
5. close() file ko properly band karta hai.
⭐ Important Point:

✔ read(n) me n characters read hote hain.
✔ Large files me limited data read karne ke liye useful hai.
✔ Character count me spaces bhi include hote hain.
