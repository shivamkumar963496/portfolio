# Question 33:
# Ek Python program likho jo lambda function ka use karke
# check kare ki number Even hai ya Odd.

# lambda function create karna
check = lambda x: "Even" if x % 2 == 0 else "Odd"

# user se number input lena
x = int(input("Enter a Number : "))

# result print karna
print("Given Number Is :", check(x))
📊 Output:

Enter a Number : 7
Given Number Is : Odd
