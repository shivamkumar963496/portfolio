📌 Python File Handling Program 21

# Question 21:
# Ek Python program likho jo binary file
# (image file) ko read kare.

# image file ko binary read mode me open karna
file = open("image.jpg","rb")

# binary data read karna
data = file.read()

# binary data print karna
print(data)

# file close karna
file.close()
📊 Output:

b'\\xff\\xd8\\xff\\xe0\\x00\\x10JFIF...'
📝 Explanation:

1. image.jpg ko binary read mode ("rb") me open kiya gaya hai.
2. Binary mode images, audio, videos aur other non-text files ke liye use hota hai.
3. read() pura binary data bytes ke form me read karta hai.
4. Output bytes format me display hota hai, jaise b'...'.
5. Last me file ko close kar diya jata hai.
⭐ Important Point:

✔ rb = Read Binary Mode
✔ Text files ke liye "r" aur binary files ke liye "rb" use kiya jata hai.
✔ Images aur multimedia files ko handle karne ke liye binary mode zaroori hota hai.
