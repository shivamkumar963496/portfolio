📌 Python File Handling Program 17

# Question 17:
# Ek Python program likho jo do files ka
# data merge karke print kare.

# first file ko read mode me open karna
f1 = open("file1.txt","r")

# second file ko read mode me open karna
f2 = open("file2.txt","r")

# dono files ka data read karna
data1 = f1.read()
data2 = f2.read()

# merged data print karna
print(data1 + data2)

# files close karna
f1.close()
f2.close()
📊 Output:

Hello World
Welcome to Python
📝 Explanation:

1. file1.txt aur file2.txt ko read mode me open kiya gaya hai.
2. read() function dono files ka content read karta hai.
3. data1 + data2 dono strings ko merge karta hai.
4. Merged content screen par print hota hai.
5. Last me dono files ko close kar diya jata hai.
⭐ Important Point:

✔ String concatenation (+) se multiple files ka data combine kiya ja sakta hai.
✔ File merging data processing aur report generation me useful hai.
✔ Large files ke liye chunk-wise merging zyada efficient hoti hai.
