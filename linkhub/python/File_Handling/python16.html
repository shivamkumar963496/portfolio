📌 Python File Handling Program 16

# Question 16:
# Ek Python program likho jo file ki
# second line display kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ki sabhi lines read karna
lines = file.readlines()

# second line print karna
print(lines[1])

# file close karna
file.close()
📊 Output:

Welcome to Python
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. readlines() file ki sabhi lines ko list me store karta hai.
3. Python me indexing 0 se start hoti hai.
4. lines[0] first line ko represent karta hai.
5. lines[1] second line ko represent karta hai.
6. Isliye second line screen par print hoti hai.
7. Last me file ko close kar diya jata hai.
⭐ Important Point:

✔ Python list indexing 0 se start hoti hai.
✔ lines[1] second line ko access karta hai.
✔ Agar file me 2 lines se kam hongi to IndexError aa sakta hai.
