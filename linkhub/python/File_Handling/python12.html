📌 Python File Handling Program 12

# Question 12:
# Ek Python program likho jo file ke content me
# kisi word ko replace kare.

# demo.txt file ko read mode me open karna
file = open("demo.txt","r")

# file ka data read karna
data = file.read()

# Python word ko Java se replace karna
new_data = data.replace("Python","Java")

# updated content print karna
print(new_data)

# file close karna
file.close()
📊 Output:

I Love Java Programming
📝 Explanation:

1. open("demo.txt","r") file ko read mode me open karta hai.
2. read() file ka pura content read karta hai.
3. replace("Python","Java") text me Python word ko Java se replace karta hai.
4. Modified text ko new_data variable me store kiya jata hai.
5. print() updated content screen par display karta hai.
6. Original file ka data change nahi hota, sirf output me replacement dikhai deta hai.
⭐ Important Point:

✔ replace() string method hai jo text ko modify karke nayi string return karta hai.
✔ Original file automatically update nahi hoti.
✔ File update karne ke liye modified data ko dobara file me write karna padta hai.
