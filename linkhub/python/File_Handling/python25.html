📌 Python File Handling Program 25

# Question 25:
# Ek Python program likho jo kisi file ka
# size bytes me display kare.

# os module import karna
import os

# file ka size nikalna
size = os.path.getsize("demo.txt")

# file size print karna
print("File Size:", size, "bytes")
📊 Output:

File Size: 120 bytes
📝 Explanation:

1. import os operating system related functions use karne ke liye import kiya jata hai.
2. os.path.getsize("demo.txt") file ka size bytes me return karta hai.
3. Returned value size variable me store hoti hai.
4. print() ke through file size display kiya jata hai.
5. File ka actual size content ke according different ho sakta hai.
⭐ Important Point:

✔ File size hamesha bytes me return hota hai.
✔ 1024 bytes = 1 KB
✔ 1024 KB = 1 MB
✔ Storage aur file management applications me ye function bahut useful hai.
