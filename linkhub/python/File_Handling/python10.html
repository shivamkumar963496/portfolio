📌 Python File Handling Program 10

# Question 10:
# Ek Python program likho jo check kare
# ki file exist karti hai ya nahi.

# os module import karna
import os

# file exist karti hai ya nahi check karna
if os.path.exists("demo.txt"):

    # agar file mil jaye
    print("File Exists")

else:

    # agar file na mile
    print("File Not Found")
📊 Output:

File Exists

OR

File Not Found
📝 Explanation:

1. import os operating system related functions use karne ke liye import kiya jata hai.
2. os.path.exists() check karta hai ki specified file ya folder available hai ya nahi.
3. Agar file mil jati hai to File Exists print hota hai.
4. Agar file nahi milti to File Not Found print hota hai.
5. Is method se error aane se pehle file availability verify ki ja sakti hai.
⭐ Important Point:

✔ File open karne se pehle existence check karna good practice hai.
✔ FileNotFoundError se bachne ke liye os.path.exists() bahut useful hai.
✔ Ye files aur folders dono par kaam karta hai.
