📌 Python File Handling Program 18

# Question 18:
# Ek Python program likho jo do files ke
# content ko compare kare.

# first file ka data read karna
f1 = open("file1.txt","r")
data1 = f1.read()

# second file ka data read karna
f2 = open("file2.txt","r")
data2 = f2.read()

# dono files compare karna
if data1 == data2:

    # agar content same ho
    print("Files are Same")

else:

    # agar content different ho
    print("Files are Different")

# files close karna
f1.close()
f2.close()
📊 Output:

Files are Same

OR

Files are Different
📝 Explanation:

1. file1.txt aur file2.txt ko read mode me open kiya jata hai.
2. read() function dono files ka pura content read karta hai.
3. == operator dono contents ko compare karta hai.
4. Agar content same hota hai to Files are Same print hota hai.
5. Agar content alag hota hai to Files are Different print hota hai.
6. Last me dono files ko close kar diya jata hai.
⭐ Important Point:

✔ == operator values compare karta hai.
✔ Comparison case-sensitive hoti hai.
✔ File comparison data verification aur backup checking me useful hai.
